How this works

You chat with a large language model. It can't touch your computer directly — instead it asks to use tools: run Python (with pandas), list/read/write files, search the web, and download pages or data. Your browser runs each tool and sends the result back. The model repeats this think → act → observe loop until it can answer. Every step is shown below as a purple card you can open.

  1. If you did not get a setup link, open Settings and enter the API key and model.
  2. Upload an Excel, Word or CSV file (or make sample data).
  3. Ask for something.
Press Enter to send, Shift+Enter for a new line.
